# Manav Gujjar — Portfolio

Premium black + yellow portfolio website for Manav Gujjar.

## Files
- `index.html` — page structure/content
- `style.css` — design and responsive styling
- `script.js` — scroll reveal, cursor and smooth scrolling

## Add your own work
Create:
- `assets/showreel.mp4`
- `assets/project-1.mp4`
- `assets/project-2.mp4`
- `assets/project-3.mp4`

Then replace the placeholder blocks in `index.html` with video elements or your YouTube/Vimeo embeds.

For large videos, YouTube/Vimeo/Cloudinary is recommended instead of storing big video files directly in GitHub.
